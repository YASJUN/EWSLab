# 输入与隐私

Android 应用只申请 `RECORD_AUDIO`，且只在用户点击接收后申请。拒绝权限不会影响 WAV 导入。没有网络权限、定位权限、后台服务或广泛存储权限。

麦克风 PCM 在内存中分析，不写入录音文件、不上传、不发送遥测。界面最近 12 块记录也只在内存中保留。应用离开前台会请求停止录音并由录音线程释放 AudioRecord；重建界面后不自动恢复录音。

WAV 通过 Android 系统文件选择器的临时 URI 权限读取，不申请永久访问整个目录。导入过程有格式、长度和内存边界；停止或切换输入后旧任务结果不会再更新界面。若文件提供程序本身正在阻塞读取，取消可能要等待该次读取返回。

生成器不自动发声，音频播放或导出由用户操作触发。项目内的测试脚本生成的是人工合成 WAV，不是用户的麦克风录音。测试输出、APK、本机 SDK 路径及签名密钥不纳入 Git。
