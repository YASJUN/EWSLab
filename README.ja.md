# EWSLab

[简体中文](README.md) | **日本語** | [English](README.en.md)

EWSLab は、日本のアナログ音声 EWS（緊急警報放送）信号を受信・解析する Android アプリです。JMA 津波電文用のオフライン信号音生成ツールを同梱しています。Android 10（API 29）以降に対応します。

現在のバージョンは **0.1.0 実験版**です。アプリの UI は簡体字中国語で、従来の EWSParserApp と同時にインストールできます。

## ダウンロードとインストール

- [v0.1.0 プレリリース：APK、オフライン生成器、SHA-256 チェックサム](https://github.com/YASJUN/EWSLab/releases/tag/v0.1.0)
- Android パッケージ：`EWSLab-0.1.0.apk`。アプリケーション ID は `xyz.ckkpd.ewsparserapp.lab` です。
- Release の APK は専用のリリース鍵で署名しています。インストール時は Android の案内に従い、ブラウザーまたはファイル管理アプリからのインストールを許可してください。

- 添付の `SHA256SUMS.txt` で APK と生成器のハッシュを確認できます。署名・ビルド・公開手順は[リリース手順（中国語）](docs/releasing.md)を参照してください。

## 使い方

1. 上記の Release から `EWSLab-0.1.0.apk` をダウンロードしてインストールします。
2. 「导入 WAV 文件」で生成器の PCM16 WAV を選択します。マイク受信の場合は「开始接收」を押し、録音権限を許可してテスト音声を再生します。
3. 単一ブロックの候補／連続確認、地域、符号化時刻、2 つの保護ビット、6 個の生の 16 ビットワードを確認します。
4. 停止操作や別のアプリへの切り替えで、受信セッションが終了します。履歴はメモリー内にのみ保持します。画面回転時もセッションを終了し、画面を再生成します。

時刻は JST で「西暦の下一桁・月・日・時」と表示します。EWS は完全な西暦、分、秒を伝送しません。時の境界付近では、奇数・偶数の保護ブロックが 1 時間異なることがあり、午前 0 時をまたぐ場合は日付も変わります。

ブラウザーで `generator/ews_tsunami_player.html` を開くと、オフラインで生成ツールを利用できます。依存パッケージのインストールやサーバーの起動は不要です。既定では送信時の現在の JST を使用します。過去の電文を再現する場合は、時刻ソースを「电文 ReportDateTime（历史重现）」に切り替え、画面の「实际编码时间」（実際の符号化時刻）を確認してください。

## ビルドとテスト

JDK 17 または 21、Android SDK プラットフォーム `android-37.0`、Build Tools 36.0.0 が必要です。生成ツールとの統合テストには Node.js 22 も必要です。Gradle Wrapper 8.14.3、AGP 8.13.0、JUnit 4.13.2 を使用し、Wrapper の設定には配布物の SHA-256 を指定しています。

Android Studio でプロジェクトを開いて SDK を設定するか、`ANDROID_HOME` を設定するか、Git 管理対象外の `local.properties` に `sdk.dir` を設定してください。

Windows では、次のコマンドを実行します。

```powershell
.\scripts\build.ps1
```

スクリプトはコアテスト、統合テスト、lint、APK ビルドを実行し、ローカル用の debug APK を `verification/local/EWSLab-debug.apk` に出力します。ソースパスに非 ASCII 文字を含む場合、中間ファイルは一時ディレクトリーに出力します。`-BuildRoot` で出力先を指定することもできます。ソースディレクトリーを出力先に指定しないでください。

Linux、macOS、または Windows の ASCII パスでは Wrapper を直接使用できます。

```sh
./gradlew :core:test :core:verifyGenerator :app:lintDebug :app:assembleDebug
```

コアテストのみを実行する場合、Node.js は不要です。

```sh
./gradlew :core:test
```

統合テストは `node scripts/generator-check.cjs` で 26 個の WAV を生成し、受信コアで 242 個の信号本体をフィールドごとに検証します。生成ファイルは `verification/local/` に保存し、Git の管理対象外としています。

ビルドと lint は成功しています。lint は `warningsAsErrors` を有効にし、baseline は使用していません。AGP 8.13.0 と SDK 37.0 の組み合わせでは互換性警告が表示されます。また、Windows の非 ASCII パスで使用する `android.overridePathCheck` にも警告が表示されます。テスト結果とツールチェーンの制限は[検証記録](docs/verification.md)を参照してください。

## 受信機能

- マイク入力は、各読み込みで実際に取得したサンプル数に基づいて処理します。
- 8 つのビット位相を探索し、640/1024 Hz の Goertzel 法と相対エネルギー判定を使用します。小数サンプルのビットクロックと破損ブロック後の再同期に対応します。
- 3 つの固定符号、フィールド識別、規定の 53 地域符号、日付・年時の符号語を検証します。
- 同じ物理ブロックの多位相結果を重複排除してから連続確認します。破損、長い間隔、種別・地域の変化、不自然な時刻変化で確認をリセットします。
- 単一ブロックは候補として表示し、条件を満たす信号本体を連続受信した後に確認済みとします。EWS には CRC がなく、有効な符号語同士の誤りには検出できないものがあります。
- 終了ブロックの 92 ビット相当の無音中もクロックを進めます。マイクと WAV は同じコアを使用します。
- Android アプリは警報の自動再生、ネットワーク通信、バックグラウンド常駐、マイク録音の保存を行いません。
